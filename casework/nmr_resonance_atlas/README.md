# NMR 共振经纬：化学位移、耦合候选与归属证据室

离线案例包（领域材料，非通用表格）。化合物：**4-乙基苯甲醚**（C9H12O，400 MHz，CDCl3，TMS）。

## 叙事线

结构化学小组把 1H/13C 一维 peak list 与 COSY/HSQC/HMBC 二维相关边合到同一个化合物分析中，
为每个核建立可复核的归属候选。

1. `baseline.json` — 初始版本：化学位移、峰强、积分、多重性、COSY/HSQC/HMBC 相关边、
   溶剂与仪器频率都按原文件（`EAN-042/*`，version 1.0）保留。所有领域量携带单位或坐标基准；
   原始表示保留（含一个 Hz 表示的溶剂峰、一个缺参考标准的卫星峰），规范化只发生在派生层。
2. `replay_log.json` — 一次参数修订（位移容差）、一次只影响局部依赖的源数据改动（补 HMBC 边）、
   一次互相冲突的人工决定（chen / garcia），以及撤销与冲突解决。
3. `counterexamples.json` — 反例档案：从基线出发每次只改动一个直接来源，覆盖
   重叠峰、对称原子、缺失相关边、化学位移整体偏置、并列最优候选、两个编辑者冲突，
   外加溶剂/温度/参考标准变更的选择性过期。被采纳与未采纳的结果都保留，
   判断依据写成机器可读的 `judgments` 事件。

## 领域规则（机器可读，见 judgments）

- `overlap.no_forced_unique`：重叠峰和缺峰不能被强制唯一匹配，耦合网络只用作证据。
- `conditions.selective_stale`：溶剂、温度或参考标准变更时只使相关候选过期，旧决定仍可重放。
- `tie.all_legal_kept`：无法唯一决定时保留全部合法候选。
- `staleness.local_scope`：局部输入变化只使依赖它的结果过期；过期结果可查看但不能冒充当前结果。
